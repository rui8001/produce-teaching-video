# 示例：为什么不是每个月都有日食

这是一个脱敏的输入示例，用来展示 Skill 在制作前需要锁定哪些信息。

## 最小输入

```text
$produce-teaching-video 把“为什么不是每个月都有日食”做成一条面向初中生的教学视频。
```

## 预期教学变化

观众不只是记住“月球轨道有倾角”，还应该能用太阳、地球、月球和交点的相对位置解释为什么大多数新月不会发生日食，并把同一模型迁移到月食判断。

## 建议画面

1. 先让观众预测“每次新月是否都会遮住太阳”。
2. 用俯视图展示新月条件，再切到侧视图暴露轨道倾角。
3. 冻结“经过交点”和“偏离交点”两种状态进行比较。
4. 用相邻问题检验：月食需要什么排列？

真正制作时仍需核对天文学来源，并明确所有比例示意并非真实尺度。
