# Anonymous user-test feedback template

Copy this form into a private reply, or use the repository's optional [GitHub usability-report form](https://github.com/rui8001/produce-teaching-video/issues/new?template=usability_report.yml) for a problem that should be public. Do not include names, email addresses, API keys, account details, private paths, student/client information, unpublished work, or full private outputs.

```text
Anonymous test ID: T__
Route: A — discovery check / B — first-use task
Codex environment: desktop / CLI / IDE extension / other
Installation route: $skill-installer / personal .agents/skills / repository .agents/skills / other
Topic category: public / synthetic
Outcome: completed / completed_with_help / blocked_install / blocked_discovery / blocked_invoke / blocked_workflow / stopped_by_choice
Approximate time: under 10 min / 10–20 min / 20–30 min / over 30 min

1. What was the first step that was unclear?

2. What was the first blocker, if any? Include reproducible, non-sensitive steps or error text.

3. What worked without help?

4. Could you identify the audience, learning objective, evidence gaps, visual explanation, and next safe step?

5. Would you use this workflow again? Why or why not?

Permissions — leave unchecked to decline:
[ ] The maintainer may publish an anonymous summary of this feedback.
[ ] The maintainer may link this test ID to a public GitHub Issue.
```

Participation does not imply either permission. The maintainer should retain only the minimum information needed to reproduce a problem and should never copy private source material into this repository.
