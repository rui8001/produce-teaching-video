# Real-user testing guide

This trial checks whether a new user can install and use the Skill without help from its author. It is not a request for stars, promotion, or artificial GitHub activity.

## Who can test

Any teacher, tutor, knowledge creator, course designer, or beginner exploring instructional video production can participate. Coding experience is not required, although installing a Codex Skill currently involves cloning or copying the repository.

## Suggested 20–30 minute trial

1. Install the repository by following the README without extra instructions from the maintainer.
2. Choose a small topic you understand well. It may be from any subject or practical skill.
3. Ask Codex to use `$produce-teaching-video` to create the learning brief and initial production plan.
4. Stop before paid services, external publishing, or full rendering unless you independently want to continue.
5. Record what was clear, what was confusing, where you became blocked, and whether the result would help a learner apply the idea.

A tester does not need to publish a finished video or share private source material.

## Feedback questions

- Could you install and invoke the Skill from the README alone?
- Did the Skill identify one clear learning objective and a realistic audience?
- Did it expose assumptions, missing sources, and model limitations instead of inventing them?
- Was the proposed visual explanation understandable and useful?
- Could you tell what to do next at every checkpoint?
- What was the first confusing or unnecessary step?
- Would you use the workflow again? Why or why not?

## How to share feedback

- Open a normal GitHub Issue for a reproducible problem or improvement.
- Send the maintainer private feedback if you do not want your identity or topic to be public.
- Never include API keys, account details, student information, client materials, unpublished course content, or copyrighted source files.

The maintainer may summarize private feedback only with the tester's permission and without identifying details.
