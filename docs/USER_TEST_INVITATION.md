# Voluntary user-test invitation

Use this text only when contacting a real person who may genuinely benefit from the Skill. Sending the invitation, receiving consent, and recording feedback are human actions; the repository does not claim that any invitation has been sent.

## Copyable invitation

```text
你好，我在维护一个开源 Codex Skill：Produce Teaching Video。它把任意学科或技能主题整理成以学习目标、来源、视觉解释和制作闸门为核心的教学视频流程。

我想邀请你自愿做一次 20–30 分钟的首次使用测试，看看一个没有参与开发的人能否从 README 独立安装，并用一个公开或虚构的小主题生成学习简报、来源台账和初始视觉计划。测试会停在付费服务、账号操作、外部上传、配音和渲染之前，不需要做出成片。

这不是请你 Star、宣传项目或公开身份。你可以随时停止，也可以只做 5–10 分钟的安装与调用测试。请不要使用学生、客户、公司、未公开课程或其他私人内容。

反馈可以私下发送。只有在你明确同意后，我才会匿名汇总；只有在你愿意公开 GitHub 账号时，才需要提交公开 Issue。

如果你愿意参与，我会把公开测试说明发给你；如果不方便，直接忽略即可。
```

## Maintainer checklist

- Do not offer rewards for stars, follows, public Issues, testimonials, or positive feedback.
- Do not count the maintainer, an automated run, or a fabricated persona as a real tester.
- Assign an anonymous ID such as `T01` only after a real invitation is sent.
- Record whether the person accepted voluntarily; do not record their name, email, workplace, or social account in the public repository.
- Send the [testing guide](./USER_TESTING.md) and [feedback template](./USER_TEST_FEEDBACK_TEMPLATE.md) without extra coaching.
- Keep declined invitations and non-responses private. They are not negative feedback.
