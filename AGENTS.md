# Repository guidance

This repository is one independently installable Codex Skill. Keep `SKILL.md` at the repository root and keep the folder, frontmatter name, examples, UI metadata, and README consistent with `produce-teaching-video`.

Never commit production media, copyrighted course scans, student data, personal paths, credentials, account data, or private project examples. Use synthetic or clearly redistributable examples.

Validate `SKILL.md`, parse YAML and JSON, inspect the tracked-file inventory, and scan for secrets before a release. Preserve automatic invocation unless a maintainer explicitly changes the policy.
