# Security and privacy

Do not report real API keys, cookies, student records, private course materials, voice samples, account exports, or unpublished production assets in a public issue.

If a report can be demonstrated safely, replace identifiers and content with a minimal synthetic example. For a sensitive disclosure, contact the maintainer privately through the security-reporting option on GitHub rather than opening a public issue.

Using this Skill does not grant permission to purchase services, access accounts, process restricted learner data, or publish media.
